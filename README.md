# justdeploy

Deploy projects without leaving your terminal.

`jd` is a CLI tool that manages Docker and Docker Compose deployments — set up a project once, then build with a single command.

## Install

```bash
cargo install --path cli
```

This installs the `jd` binary to `~/.cargo/bin/`.

## Quick Start

```bash
# In your project directory
jd setup

# Build
jd build

# See all registered projects
jd list
```

## Commands

| Command | Description |
|---|---|
| `jd setup` | Interactively create a `jd.json` config for the current project |
| `jd build` | Build the project using its `jd.json` config |
| `jd list` | List all registered deployments |

## Setup

Running `jd setup` will:

1. Prompt for a deployment name (auto-generated if skipped)
2. Prompt for the project directory (defaults to current directory)
3. Auto-detect a `Dockerfile` or `docker-compose` file in the directory
4. Ask which file to use, or let you enter a custom path
5. Write a `jd.json` to the project directory

Re-running `jd setup` on an existing project backs up the current config to `jd.json.old` before writing the new one.

## Configuration

`jd.json` is generated by `jd setup` and lives in your project root:

```json
{
  "name": "my-app",
  "version": "0.1.0",
  "project_dir": "/path/to/my-app",
  "deployment_type": "Dockerfile",
  "file_path": "/path/to/my-app/Dockerfile",
  "server": "Local"
}
```

Edit this file directly — `jd build` and `jd list` always read it fresh.

## Registry

`jd` tracks all registered projects in `~/.justdeploy/registry.json`. Only the path to each project's `jd.json` is stored — no config data is duplicated.
